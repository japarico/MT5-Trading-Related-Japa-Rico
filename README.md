# MT5 PVSRA Indicator & OrderLimitEA

A collection of tools for MetaTrader 5 (MT5 / MQL5) designed to aid chart analysis and execution. All files in this repository are formatted strictly for the MT5 platform.

This project is shared **100% free of charge** for the community.

---

## 🛠️ Included Tools

### 1. PVSRA Indicators (`/PVSRA`)
* **Author:** Fernando H Rosa
* **Platform:** MT5 (MQL5)
* **Description:** Price Volume Support Resistance Analysis (PVSRA) tools to help analyze volume and price action.
* **Special Thanks:** These indicator files were **not coded by me**. Huge credit and sincere gratitude go to **Fernando H Rosa** for developing and sharing these MQL5 scripts with the trading community.

### 2. OrderLimitEA (`/OrderLimitEA`)
* **Author:** Japa Rico
* **Platform:** MT5 (MQL5)
* **Description:** An Expert Advisor designed to streamline limit order placement and trade execution on MT5.
