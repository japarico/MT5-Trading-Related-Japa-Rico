Installation Instructions

Extract the files inside the MQL5 folder (File > Open Data Folder).

The subfolders are already configured, so you don't need to move them one by one;

***Make sure to also download the indicators from the links above ^

Right-click on the chart, go to Templates, and click "Load Template".

Open the template "PVSRA mt5 v2-1.tpl";

Open the "Navigator" window and add all the indicators *add the Dragon indicator first;

The "Force Numbers" indicator is configured for Forex via the files in the "sets" folder. If you are going to use it for Stocks, you will need to change the settings manually.

For Forex: open the Navigator and add the "Force Numbers" indicator,

Click on the "Inputs" tab,

Click "Load",

Select the "fn1..." file and click OK,

Repeat the process to add the fn2, fn3, and fn4 files.
